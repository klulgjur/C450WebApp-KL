## 1. Brand Principles
The design should be simple and approachable. The focus should be on the reference articles, avoiding excessive design elements that can be distracting. Because it is geared towards non-technical users, it should have a friendly, accessible interface. 

## 2. Color Palette
- Name: Primary
    - Hex: #142F40
    - Use: main brand color, primary buttons, logos. Dark accent color for high contrast, page dividers, borders, titles, links
- Name: Secondary
    - Hex: #95A58D
    - Use: Lighter accent color to use as background for key elements such as article cards, header, etc.
- Name: Background
    - Hex: #F4F3E6
    - Use: page background
- Name: Text
    - Hex: #000000
    - Use: body text, important labels, forms, etc.

## 3. Typography
All text should be in the Arial font-family. 
- Headings/titles should be 35px and bold
- Subheadings should be 25px and italicized
- body text should be 18px and regular. 

## 4. Logo Usage
- Logo will be Bootstrap's standard computer mouse icon

## 5. Spacing and Grid
- base unit for spacing should be 10px between elements
- Grid: 6 column grid

## 6. Core Components
- Button (primary)
    - Primary color background, bold and centered white text, rounded corners
- Card
    - secondary color background, primary color border
- Article titles and subheadings
    - primary color, tooltip with full article title when hovered over (for when title is too long to fit in card)
- icons
    - primary color, basic commonly used icons for menu, profile, bookmarks
- forms
    - white box with black border for text entry, black text for labels

## 7. Voice and Tone
- tone: casual, warm, approachable
    - use plain, concise language

## 8. Accessibility Standards
- Minimum contrast ratio: 4.5:1 for body text (WCAG AA)
- left-align body text for easier legibility
- Include descriptive alt text for images
