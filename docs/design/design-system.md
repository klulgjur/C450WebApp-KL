# Design System — Cyber-Toolkit

## 1. Brand Principles
Cyber-Toolkit should feel simple, approachable, and easy to trust. The design should stay focused on the reference articles and avoid unnecessary visual distractions so users can quickly find useful information without feeling overwhelmed. Because the app is intended for non-technical users, the interface should feel friendly, clear, and accessible from the first interaction.

## 2. Color Palette

| Name | Hex | Use |
|------|-----|-----|
| Primary | #142F40 | Main brand color, primary buttons, logos, page dividers, borders, titles, and links |
| Secondary | #95A58D | Light accent color for key surfaces such as article cards and header backgrounds |
| Background | #F4F3E6 | Page background |
| Text | #000000 | Body text, labels, forms, and important content |

## 3. Typography

| Role | Font | Size | Weight |
|------|------|------|--------|
| Heading / Title | Arial | 35px | Bold |
| Subheading | Arial | 25px | Italic |
| Body | Arial | 18px | Regular |

All text should use the Arial font family, with consistent sizing and clear hierarchy to support readability and easy scanning.

## 4. Logo Usage
- File(s): Bootstrap standard computer mouse icon
- Use: Keep the icon simple, clean, and centered in the header or brand area.
- Do NOT: stretch, recolor, or place the icon on busy backgrounds; avoid decorative effects that reduce readability.

## 5. Spacing & Grid
- Base unit: 10px
- Grid/columns: 6-column grid
- Standard spacing scale: 10 / 20 / 30 / 40 / 50px
- Layout should use consistent spacing between elements to maintain visual order and avoid clutter.

## 6. Core Components

| Component | Rules |
|-----------|-------|
| Button (primary) | Primary background color, centered white text, bold weight, rounded corners, clear spacing for tap/click targets |
| Card | Secondary background, primary color border, consistent padding, simple layout that highlights article information |
| Article titles and subheadings | Primary color text, bold hierarchy, and a hover tooltip showing the full article title when the text is too long to fit in the card |
| Icons | Primary color, simple and consistent iconography for menu, profile, and bookmarks |
| Forms | White input boxes with black borders, black labels, and legible text for easy entry |

## 7. Voice & Tone
- Tone: casual, warm, approachable
- Use plain, concise language that feels friendly and easy to understand.
- Keep text short and direct, with no unnecessary jargon or complicated phrasing.
- Writing should support confidence and clarity for non-technical users.

## 8. Accessibility Standards
- Minimum contrast ratio: 4.5:1 for body text (WCAG AA)
- Standard to meet: WCAG AA
- Left-align body text for easier readability.
- Use descriptive alt text for all images.
- Maintain strong visual contrast and clear spacing so the interface remains readable and easy to navigate.
