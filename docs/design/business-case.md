# Business Case — [Product/Service Name]

## 1. Problem / Opportunity
What's the situation today, and why does it matter? (1–2 sentences)
As our lives become more digitized, it is important to stay vigilant and informed on security habits and tools available to protect personal information online. However, technical jargon and usability issues prevent individuals from engaging with technology safely. These barriers put individuals at increased risk of cyberthreats.

## 2. Proposed Solution
One paragraph, plain language, no implementation detail.
The proposed app seeks to support those with less technological inclination by providing simple, accessible learning resources. It will feature quick guides that break down complex vocabulary and concepts, walk through building safe digital habits, and analyze examples of potential cyberthreats. These tools aim to make cybersecurity more approachable so individuals can confidently engage with technology safely.

## 3. Options Considered

| Option | Description | Pros | Cons |
|--------|-------------|------|------|
| Option A | Gamified web application allowing users to engage with cybersecurity scenarios to practice reacting to cyberthreats. | Engaging, appealing to younger audiences, hands-on learning, potential for social interaction | Stronger focus on intermediate technology proficiency, limitation to younger audiences, more difficult implementation |
| Option B (recommended) | Article-focused web application with simplified cybersecurity information and examples of cyberthreats.| Stronger focus on introductory skills, accessible to a wider audience, easier to maintain | Less engaging than an interactive application, less incentive to return regularly |

## 4. Feasibility

| Type | Assessment |
|------|------------|
| Operational — will people actually use/support this? | The application will likely be used as a reference tool to assess potential threats as they occur. |
| Technical — can we build it with what we have/can get? | A web application is technically achievable using basic development tools, and content for the application can be acquired through research.  |
| Economic — does the payoff justify the cost? | Because this is a reference tool, financial costs will likely be minimal. |
| Schedule — can it be done in a useful timeframe? | The application can be achieved within a useful timeframe because it focuses on beginner level information rather than covering all cybersecurity topics. |

## 6. Priority & Urgency
Why now? What happens if we wait or don't do it?
If cybersecurity awareness isn’t prioritized, we leave those with less technical inclination vulnerable to cyberthreats. Because of the widespread use of technology across many aspects of our lives, it is becoming increasingly difficult to avoid using it in some way. Thus, it is necessary to ensure individuals have the tools available to make informed decisions online.

## 7. Recommendation
One sentence: which option, and the go/no-go ask.
I recommend going with Option B, the article-focused web app. Due to the simplicity and limited cost, it is accessible to a broader audience without the additional time and/or financial commitment of a complex, gamified app.
